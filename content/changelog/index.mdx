# Changelog

All notable changes to this project will be documented in this file.

## [2026-01-07]

### Added
- **Search Highlighting**: Search terms are now highlighted in the documentation search results for better visibility.
- **Deep Linking**: Clicking a search result now navigates directly to the closest heading anchor.
- **PWA Installation Guides**: Added platform-specific instructions for iOS, Android, and Desktop (Chrome/Edge).
- **Sync Improvements**: Added auto-merge for non-conflicting items and a more intuitive manual conflict resolution modal.
- **Statistics**: Added "Similar Verse Coverage" chart to the Statistics tab.
- **UI Enhancements**: Added dynamic mindmap previews and optimized layouts for tablet and mobile headers.
- **Onboarding**: Improved the onboarding progress bar and ensured it correctly triggers for new users.

### Changed
- **Documentation Overhaul**: Major restructuring into "Philosophy" and "Application" sections with simplified, jargon-free language.
- **Mindmap Strategy**: Refined the workflow to encourage early mindmap creation to decrease rote memorization time.
- **Sync Logic**: Transitioned to auto-sync on load and manual sync via a dynamic toolbar button with clear labels.
- **Daily Portion Logic**: Intelligent merging of short trailing segments and added "Isti3atha" display for mid-surah starts.
- **Review System**: Clarified "Not Sure" (Postpone) button usage and automated Mutashabihat flagging in the Todo tab after errors.
- **Settings**: Redefined "Skipping Surahs" for mastered texts and restricted AnchorBuilder to create/edit modes.

### Fixed
- **Sync & Offline**: Resolved issues with offline launching and corrected sync count tracking.
- **Mobile Layout**: Fixed various mobile UI issues, including header sizes, icon alignments, and empty states.
- **Vercel Build**: Resolved several build-related errors for deployment.

### Removed
- **Obsolete Sections**: Removed "Mindmap Meta" and outdated "periodic sync" descriptions.
