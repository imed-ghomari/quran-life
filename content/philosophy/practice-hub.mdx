# Active Practice Hub

The Practice tab is the main working space for active memorization. It replaces the old habit of switching between a Today review view and a separate Todo/Kanban board.

## Queue Summary First

When you open Practice, the review section starts with a summary card. It shows three active queues:

1. **Prep** — mindmaps or verse splits that need setup before they can become review material.
2. **SRS** — due spaced-repetition review cards.
3. **Repair** — suspended error cards and similarity checks created from review mistakes.

Press **Begin practice** to enter the active review flow. Use the back control in the Practice header to return to the summary.

## Adaptive Priority

Practice follows this order:

1. If SRS cards are due, review them first.
2. When SRS is clear, use the preparation queue for unfinished active-part mindmaps and splits.
3. Repair cards sit after SRS so repeated errors and mutashabihat checks can be handled in context without opening a Kanban board.

This keeps the learning pipeline in one place: **Preparation → Retrieval → Repair**.

## Preparation Queue

Preparation cards show the item name and the same actions that used to live in the Kanban card menu:

- Create or edit the mindmap.
- Change splits for Surah cards.
- Open the relevant mindmap documentation.

A mindmap becomes review-ready when it is marked complete, has mindmap content, and has usable splits. Short Surahs can still use the automatic single split where supported by the app.

## Remediation Queue

Repair work is created from review failures:

- **Error cards** appear when a verse group reaches the repeated-error suspension threshold.
- **Similarity cards** appear from mutashabihat-related failed chunks.

Repair cards show their context inline so you can see why the item exists before taking action. Their action buttons mirror the old Kanban submenu: edit the mindmap, edit splits, open verse context, open similarity context, ignore similarity, or jump to similarity settings as appropriate.

## Passive Consumption

The Daily Portion remains on the Practice page as the passive consumption section. It is separate from the active review queue but still part of the same daily workflow.
