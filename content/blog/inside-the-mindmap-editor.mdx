# Inside the mindmap editor: how the mapping tools actually work

Quran Life's mindmap editor is built on top of tldraw, so it behaves like a real canvas rather than a text field pretending to be visual.

The editor starts from a lasso-style selection workflow, which fits mindmapping better than forcing you into ordinary box-selection first. From there you can switch between the main tools you actually need while mapping: hand navigation, drawing, arrows, text, highlighting, erasing, and normal selection.

It also includes some practical safeguards that matter in real use. The editor keeps local draft state, autosaves changes, updates snapshots as you work, restores local drafts after interruptions, and tries to save before letting you exit. It also adapts to light and dark theme, zooms to fit when loading a map, and includes a few protections around paste, drag-drop media, and pen-mode glitches.

So the important thing to understand about the editor is not only that it exists. It is that Quran Life treats it as an actual working environment for mapping, not as a decorative attachment on the side.
