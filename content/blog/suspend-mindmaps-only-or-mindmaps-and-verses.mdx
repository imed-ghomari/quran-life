# When Quran Life suspends only the mindmap, and when it suspends both the mindmap and the verses

Not every reset should destroy the same amount of progress.

Sometimes the map needs to leave review because the structure is no longer trustworthy, while the verse groups themselves can remain. In other cases, the split changes are deep enough that both structure and verse-level review need to be suspended together.

This distinction matters because it respects partial stability. A reset should be honest, but it should not be wasteful.

If part of the work is still valid, the system should preserve it.
