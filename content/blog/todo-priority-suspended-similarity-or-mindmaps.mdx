# Suspended, similarity, or mindmaps: what should you prioritize in your todo?

Not every todo item carries the same urgency, and the wording only helps if it stays consistent.

The simplest order is this: first do the mindmap work that gives you structure, then fix suspended verse groups, then resolve similarity cards. That wording is easier because each label points to one kind of work instead of mixing several names for the same idea.

Why this order? Because unresolved structure makes everything else weaker. Suspended verse groups come next because they point to a concrete break in review. Similarity cards are important too, but they usually become easier once the map and the verse stability are already in place.

So the rule is not complicated: build the structure, fix the broken review groups, then clean up the fine distinctions.
