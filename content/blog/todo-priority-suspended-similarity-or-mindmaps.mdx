# Suspended, similarity, or mindmaps: what should you prioritize in your todo?

Not every todo item carries the same urgency. The right priority depends on whether the problem is structural, corrective, or comparative.

If a verse group is suspended, that usually means something is actively broken in recall and needs attention soon. If a mindmap is missing or incomplete, that is a structural weakness that may block future stability. Similarity work matters too, but often becomes most useful once the main structure is already in place.

So the rough order is often: fix broken structure, then repair unstable recall, then resolve distinctions.

That order is not about ranking features. It is about asking which problem is currently preventing everything else from becoming easier.
