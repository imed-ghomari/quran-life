# Mindmap Legend (Read First)

Use this page as a **reference key** for the symbols used in mindmap documentation.
Check this legend first before reading any Part or Surah mindmap page.

## Symbol Key

| Symbol | Meaning |
|---|---|
| `[]` | Main node or major concept |
| `()` | Supporting detail or explanation |
| `->` | Direction or progression |
| `<->` | Two-way relationship |
| `=>` | Cause and effect |
| `==` | Strong thematic connection |
| `...` | Continuation or omitted details |
| `!` | Important point |
| `?` | Review question / area to revisit |
| `*` | Memorization focus |

## How To Use This With Other Mindmaps

1. Open this legend first.
2. Keep these meanings in mind while reading Part and Surah mindmaps.
3. If a symbol is updated in future mindmaps, update this legend page first.

## Note

This is the canonical legend for documentation mindmaps.
If a symbol appears unclear in any page, refer back to this file.
