# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2026-01-07]

### Added
- **Search Highlighting**: Search terms are now highlighted in the documentation search results and briefly on the destination page for better visibility.
- **Deep Linking**: Clicking a search result now navigates directly to the closest heading anchor.
- **PWA Installation Guides**: Added platform-specific instructions for iOS, Android, and Desktop (Chrome/Edge).
- **Sync Improvements**: Added auto-merge for non-conflicting items and a more intuitive manual conflict resolution modal.
- **Statistics**: Added "Similar Verse Coverage" chart to the Statistics tab.
- **UI Enhancements**: Added dynamic mindmap previews and optimized layouts for tablet and mobile headers.
- **Onboarding**: Improved the onboarding progress bar and ensured it correctly triggers for new users.

### Changed
- **Documentation Overhaul**: Major restructuring into "Philosophy" and "Application" sections with simplified, jargon-free language.
- **Mindmap Strategy**: Refined the workflow to encourage early mindmap creation to decrease rote memorization time.
- **Sync Logic**: Transitioned to auto-sync on load and manual sync via a dynamic toolbar button with clear labels.
- **Daily Portion Logic**: Intelligent merging of short trailing segments and added "Isti3atha" display for mid-surah starts.
- **Review System**: Clarified "Not Sure" (Postpone) button usage and automated Mutashabihat flagging in the Todo tab after errors.
- **Settings**: Redefined "Skipping Surahs" for mastered texts and restricted AnchorBuilder to create/edit modes.

### Fixed
- **Sync & Offline**: Resolved issues with offline launching and corrected sync count tracking.
- **Mobile Layout**: Fixed various mobile UI issues, including header sizes, icon alignments, and empty states.
- **Vercel Build**: Resolved several build-related errors for deployment.
- **Mindmap Viewer**: Fixed missing `useEffect` import in `MindmapViewer.tsx` that caused compilation failure.

### Removed
- **Obsolete Sections**: Removed "Mindmap Meta" and outdated "periodic sync" descriptions.

## [2025-12-27]

### Fixed
- **Production Crashes**: Resolved critical Tldraw crashes in production by implementing a unique `persistenceKey` and a robust `ErrorBoundary`.
- **Blank Screen Issues**: Fixed blank screen interface by disabling React Strict Mode, ensuring proper CSS loading, and using dynamic imports with SSR disabled for the Mindmap Editor.
- **Asset Loading**: Hardcoded Tldraw asset URLs to prevent missing resource errors in production environments.
- **Code Stability**: Fixed `ReferenceError` in storage logic and removed duplicate React hooks that caused render crashes.
- **Debug Tools**: Enhanced the debug overlay with layout and state diagnostics to better identify UI issues.

## [2025-12-26]

### Added
- **Review UI**: Enhanced the review system interface for better user experience.
- **Offline Support**: Improved application reliability when working without an internet connection.
- **Mobile Design**: Added slide-over designs for "Similar Verse Coverage" and optimized documentation layouts for mobile devices.

### Changed
- **UI Optimization**: Refined settings and todo pages for better mobile usability and layout polish.

## [2025-12-25]

### Added
- **Knowledge Tracking**: Introduced "Memory Nodes Transparency" section in settings to track memorization progress.
- **PWA Enhancements**: Added new PWA icons and updated configuration for better installation support.
- **Mindmap Tools**: Added zoom functionality to the mindmap editor.

### Changed
- **Rebranding**: Renamed the application to **Quran Life**.
- **Terminology**: Transitioned from "Maturity" to "Knowledge Tracking" across the interface.
- **Mobile Layout**: Removed redundant card styles and improved space utilization for mobile screens.
- **Logic Improvements**: Refined daily portion division and surah ordering.

### Fixed
- **Sync Persistence**: Resolved issues with Supabase sync data not persisting correctly.
- **Type Safety**: Fixed various TypeScript errors related to memory nodes and settings.

## [2025-12-24]

### Added
- **Infrastructure**: Initial project setup with Supabase integration and Vercel deployment configuration.
- **PWA Support**: Added manifest, metadata, and SVG icons to enable PWA installation.
- **Core Features**: Initial implementation of cross-tab sync and review due dates.

### Fixed
- **Compatibility**: Downgraded ESLint for Next.js 14 compatibility and resolved initial Vercel build errors.
- **Sync Loops**: Prevented infinite sync loops and resolved dark mode UI persistence issues.
