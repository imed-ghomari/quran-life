# Quran Life — Obsidian Plugin

Daily Qur'an review, mindmap memorization and Anki export, vault-synced via Resilio Sync.

## Development

```bash
npm run build
```

## Release

```bash
npm run plugin:release
```

Releases are published from the `main` branch.
