# Suspended, similarity, or mindmaps: what should you fix first each week?

Not every review signal carries the same urgency. Once a week, open the Anki Browser and triage in this order:

The simplest order is this: first do the mindmap work that gives you structure, then fix suspended verse groups, then resolve similarity cards.

Why this order? Because unresolved structure makes everything else weaker. Suspended verse groups come next because they point to a concrete break in review. Similarity cards are important too, but they usually become easier once the map and the verse stability are already in place.

So the rule is not complicated: build the structure, fix the broken review groups, then clean up the fine distinctions.
