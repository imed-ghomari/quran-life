# Mindmap Legend

Use this page as a **reference** for the symbols used in mindmaps.
Refer back here whenever a map uses a symbol you don't recognize.

## Pre-made mindmaps — in preparation

> The official pre-made mindmap collection is still being prepared, so there
> is currently **nothing to download here yet**. When it is ready, download
> and import instructions will appear in this section. You don't need to wait
> — you can already create your own mindmaps in the plugin.

## Sharing mindmaps (optional)

> You don't have to create and share everything yourself. But if you want to
> exchange maps with other users, in **Anki Deck** the MINDMAPS card has
> **Export** (pick your maps and build a `.zip`) and **Import** (pick a shared
> `.zip` and bring it in). See [Getting Started](../philosophy/getting-started#2b-share-mindmaps-import--export).
